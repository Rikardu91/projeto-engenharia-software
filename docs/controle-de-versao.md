\# Controle de Versão do Projeto



\## Ferramentas utilizadas

\- Git: sistema de controle de versão.

\- GitHub: plataforma de hospedagem do repositório.



\## Organização

O projeto utiliza as pastas src, docs e testes para organizar seus arquivos.



\## Histórico de versões

As alterações são registradas por meio de commits, que permitem acompanhar a evolução do projeto.



\## Objetivo

Manter o histórico de alterações organizado, facilitando o acompanhamento e a manutenção do projeto.
